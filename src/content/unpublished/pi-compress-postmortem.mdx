The idea is older than me: if π is a normal number, every finite sequence of
digits is in it somewhere. So instead of storing a file, store where to find it
in π. I built it in Rust and shipped it on the first of April, and it works.
Every file it touches comes out larger.

## How it works

Each byte becomes two hex digits, the tool searches the first million digits of
π for the longest run of input it can find, and it writes out instructions
rather than data: `Pi[index] (N bytes)` for a hit, `Raw[0xHH]` for a miss.

## Why it can never win

π only has the digits 0–9. A hex pair with a letter in it, `4a` or `8b`, can't
be found, and that's about a third of all possible bytes. The rest are found
at an index that is usually longer than what it replaces.
