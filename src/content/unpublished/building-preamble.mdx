My music library had a decade of duplicates, half-tagged rips, and files that
decoded to silence in it, and no GUI tool would tell me which was which without
a lot of clicking. So I wrote preamble: a terminal app that scans the library
into SQLite and puts a keyboard-driven TUI on top.

## Never delete anything

Deletion is staged: `d` flags a track, purging moves it to quarantine instead
of unlinking it, and `z` undoes. The database records what happened; the files
are only ever moved.
